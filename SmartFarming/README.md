# SmartFarming AI - Inteligência Artificial para Gestão do Agronegócio

Plataforma inteligente para monitoramento, gestão de rebanhos, sustentabilidade e automação operacional no agronegócio.

## 🌾 Visão Geral

O projeto SmartFarming AI combina inteligência artificial generativa, visão computacional e telemetria para otimizar operações agropecuárias, monitoramento de pastagens e gado, e integração com WhatsApp para tomada de decisão em campo.

- `HISTORICO_CONVERSA_SMARTFARMING.md`: Registro completo de concepção, arquitetura de dados e roadmap de engenharia da solução SmartFarming.

## 🔗 Integração

Conecta-se com a Evolution API e módulos ERP para gestão pecuária e relatórios automatizados de produtividade e manejo.
