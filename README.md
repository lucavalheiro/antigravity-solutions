## 🛠️ Stack Tecnológica Global

- **Inteligência Artificial & Agentes:** Google Gemini API, IBM Watsonx, Aider, Antigravity Agentic Framework, MCP (Model Context Protocol).
- **Computação Quântica:** Qiskit, QAOA (Quantum Approximate Optimization Algorithm), QPU Benchmarking.
- **Observabilidade & Infraestrutura:** IBM Instana, IBM Turbonomic ARM, GLPI Service Desk, Docker, Docker Compose, Linux/Ubuntu com GPU NVIDIA L4.
- **Backend & APIs:** Python 3.10+, FastAPI, Pydantic, Uvicorn, SQLite, Node.js/JavaScript.
- **Comunicação & Mensageria:** WhatsApp Evolution API, Webhooks, REST APIs.

---

## 🔒 Segurança e Boas Práticas

- Arquivos com chaves de API, senhas e credenciais reais são protegidos e excluídos via `.gitignore`.
- Modelos de configuração são disponibilizados como `.env.example`.
- Arquivos binários pesados (instaladores, vídeos e ambientes virtuais) são mantidos fora do controle de versão para manter o repositório leve e ágil.
